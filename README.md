# 🎬 모션 스튜디오 (motion-studio) v2.0

텍스트를 입력하면 모션그래픽 영상을 만들어주는 웹앱. Remotion/HyperFrames 아이디어의 브라우저판 — 코드 기반 모션그래픽을 Canvas에 렌더링하고 MediaRecorder로 녹화한다. 100% 브라우저에서 동작하며 외부 서버가 없다.

## 사용법

1. **텍스트 입력**: 제목 / 부제 / 로고 이모지 / 자막(가라오케용, 한 줄에 하나씩)
2. **템플릿 선택** (5종)
   - ⚡ 키네틱 타이포: 단어가 시간차로 튀어오르며 등장
   - 📺 로어 서드: 방송 자막처럼 하단 바 슬라이드인 (제목=이름, 부제=직함, 하단 고정)
   - 🎤 가라오케 자막: 단어가 타이밍에 맞춰 하이라이트
   - ✨ 로고 스팅어: 플래시와 함께 로고 등장 인트로
   - ⌨️ 타자기 효과: 글자가 한 자씩 타이핑되며 커서 깜빡임 (영상 배경 위에서도 동작)
3. **설정**
   - **배경**: 단색(컬러 피커) / 이미지 업로드 / 동영상 업로드 (cover 방식, 동영상은 재생·루프)
   - **딤**: 배경 어둡게 조절 슬라이더 (0~80%)
   - **색상 프리셋** 6종 + 직접 선택 (배경 / 강조)
   - **텍스트 스타일**: 굵기(보통/굵게/아주굵게), 외곽선(두께+색상), 그림자, 그라데이션 채우기(강조색→흰색), 자간
   - **텍스트 위치**: 3x3 그리드 (로어 서드는 하단 고정)
   - 화면 비율(16:9 / 9:16 / 1:1), 길이(3초/5초/10초)
   - **애니메이션 속도**: 0.5x ~ 2x
   - **오디오**: 무음 / 앰비언트(AI 생성 패드) / 오디오 파일 업로드
4. **미리보기**: ▶ 재생 / ⏸ 정지 / ⏮ 처음부터, 타임라인 진행 바
5. **녹화**: "● 녹화 시작" → 처음부터 끝까지 자동 재생·녹화 → WebM/MP4 다운로드. 오디오를 켜면 소리도 함께 녹음된다.

## 기술

- `requestAnimationFrame` + 경과 시간 기반 애니메이션 (프레임 인덱스의 순수 함수처럼 동작)
- 이징 직접 구현: easeOutCubic, easeInOutCubic, easeOutBack, easeOutExpo
- 스타일 텍스트 렌더러: 굵기/외곽선/그림자/그라데이션/자간을 모든 템플릿에 일괄 적용
- 업로드 파일은 `URL.createObjectURL`로 메모리에만 유지 (서버 전송 없음)
- 녹화: `canvas.captureStream(30)` + MediaRecorder (코덱 자동 선택: vp9 → vp8 → webm → mp4)
- 오디오: WebAudio → MediaStreamDestination으로 녹화 스트림에 결합 (패드/파일 모두)
- 외부 의존성 0 (CDN 없음, 시스템 폰트만 사용)

## 제약

- MediaRecorder 미지원 브라우저에서는 녹화가 동작하지 않음 (최신 Chrome/Edge/Firefox/Safari 지원)
- 브라우저에 따라 저장 포맷이 WebM 또는 MP4로 달라짐
- `ctx.letterSpacing` 미지원 브라우저에서는 자간 조절이 적용되지 않을 수 있음
- 큰 동영상 파일은 메모리를 많이 사용하므로 짧은 클립 권장

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages로 배포하면 바로 사용할 수 있다.
