# 🎬 모션 스튜디오 (motion-studio)

텍스트를 입력하면 모션그래픽 영상을 만들어주는 웹앱. Remotion/HyperFrames 아이디어의 브라우저판 — 코드 기반 모션그래픽을 Canvas에 렌더링하고 MediaRecorder로 녹화한다. 100% 브라우저에서 동작하며 외부 서버가 없다.

## 사용법

1. **텍스트 입력**: 제목 / 부제 / 로고 이모지 / 자막(가라오케용, 한 줄에 하나씩)
2. **템플릿 선택** (4종)
   - ⚡ 키네틱 타이포: 단어가 시간차로 튀어오르며 등장
   - 📺 로어 서드: 방송 자막처럼 하단 바 슬라이드인 (제목=이름, 부제=직함)
   - 🎤 가라오케 자막: 단어가 타이밍에 맞춰 하이라이트
   - ✨ 로고 스팅어: 플래시와 함께 로고 등장 인트로
3. **설정**: 색상 프리셋 6종 + 직접 선택, 화면 비율(16:9 / 9:16 / 1:1), 길이(3초/5초/10초), 배경음악 토글(WebAudio 앰비언트 패드, 외부 파일 없음)
4. **미리보기**: ▶ 재생 / ⏸ 정지 / ⏮ 처음부터, 타임라인 진행 바
5. **녹화**: "● 녹화 시작" → 처음부터 끝까지 자동 재생·녹화 → WebM/MP4 다운로드. 음악을 켜면 소리도 함께 녹음된다.

## 기술

- `requestAnimationFrame` + 경과 시간 기반 애니메이션 (프레임 인덱스의 순수 함수처럼 동작)
- 이징 직접 구현: easeOutCubic, easeInOutCubic, easeOutBack
- 텍스트 자동 맞춤: 캔버스 너비에 맞춰 폰트 크기 자동 조절
- 녹화: `canvas.captureStream(30)` + MediaRecorder (코덱 자동 선택: vp9 → vp8 → webm → mp4)
- 오디오: WebAudio → MediaStreamDestination으로 녹화 스트림에 결합
- 외부 의존성 0 (CDN 없음, 시스템 폰트만 사용)

## 제약

- MediaRecorder 미지원 브라우저에서는 녹화가 동작하지 않음 (최신 Chrome/Edge/Firefox/Safari 지원)
- 브라우저에 따라 저장 포맷이 WebM 또는 MP4로 달라짐
- 배경음악은 WebAudio로 합성한 간단한 앰비언트 패드 (외부 음원 아님)

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages로 배포하면 바로 사용할 수 있다.
